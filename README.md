# ProofGate

**Agent confidence is not permission to act.**

ProofGate is a pre-execution control plane for autonomous AI agents.

It converts verified Telegraph intelligence into a short-lived,
single-use authorization bound to one exact proposed action.

Core flow:

PROPOSE → PROVE → PERMIT → EXECUTE → RECEIPT

## Core Security Properties

- Exact-action binding
- Fail-closed policy evaluation
- Short-lived permits
- Single-use nonces
- Replay protection
- Action tamper detection
- Telegraph-backed evidence
- Controlled execution
- Persistent proof receipts
